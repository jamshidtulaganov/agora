Tandem CLI は、Web UI でできるほぼすべての操作をそのまま提供します（[イシュー](/issues)の作成、[エージェント](/agents)の割り当て、[デーモン](/daemon-runtimes)の起動など）。このページでは、すべてのトップレベルコマンドを 1 行の説明とともに一覧します。フラグや例の完全な一覧は `tandem <command> --help` を実行してください。

## 認証する

CLI を初めて使うときにこのコマンドを実行して、**パーソナルアクセストークン（PAT）**を取得します。

```bash
tandem login
```

ブラウザが自動的に開きます。Web アプリで承認すると、CLI が PAT（`mul_` プレフィックス付き）を `~/.tandem/config.json` に保存します。これ以降のすべてのコマンドはこの PAT で認証されます。

<Callout type="tip">
CI やヘッドレス環境では、ブラウザフローをスキップできます。Web アプリの **Settings → Personal Access Tokens** で PAT を作成し、`tandem login --token <mul_...>` で直接渡してください。
</Callout>

トークンの種類による違いについては、[認証とトークン](/auth-tokens)を参照してください。

## 認証とセットアップ

| コマンド | 用途 |
|---|---|
| `tandem login` | ログインして PAT を保存 |
| `tandem auth status` | 現在のログイン状態、ユーザー、ワークスペースを表示 |
| `tandem auth logout` | ローカルの PAT を削除 |
| `tandem setup cloud` | Tandem Cloud のワンショットセットアップ（ログイン + デーモンのインストール） |
| `tandem setup self-host` | セルフホストバックエンドのワンショットセットアップ |

## ワークスペースとメンバー

| コマンド | 用途 |
|---|---|
| `tandem workspace list` | アクセスできるすべてのワークスペースを一覧 |
| `tandem workspace get <slug>` | 1 つのワークスペースの詳細を表示 |
| `tandem workspace member list` | 現在のワークスペースのメンバーを一覧 |
| `tandem workspace update <id> --name "..." [--description "..."] [--context "..."] [--issue-prefix "..."]` | ワークスペースのメタデータを更新（admin/owner）。長いフィールドは `--description-stdin` / `--context-stdin` を使用できます。 |

## イシューとプロジェクト

<Callout type="info">
`list` 系のコマンド（`tandem issue list`、`autopilot list`、`project list` など）は、デフォルトで短く**そのままコピー＆ペーストできる** ID を出力します。イシューは `MUL-123` のようなイシューキー、それ以外のリソースは短い UUID プレフィックスです。以下の後続コマンドの `<id>` 引数は短い ID と完全な UUID のどちらも受け取るため、一般的な流れは `tandem issue list` → キーをコピー → `tandem issue get MUL-123` となります。正式な UUID が必要なときは `list` コマンドに `--full-id` を渡してください。
</Callout>

| コマンド | 用途 |
|---|---|
| `tandem issue list` | イシューを一覧（コピー＆ペーストできるイシューキーを出力） |
| `tandem issue get <id>` | 単一のイシューを表示（イシューキーまたは UUID を受け取る） |
| `tandem issue create --title "..."` | 新しいイシューを作成 |
| `tandem issue update <id> ...` | イシューを更新（ステータス、優先度、担当者など） |
| `tandem issue assign <id> --agent <slug>` | エージェントに割り当て（即座にタスクをトリガー） |
| `tandem issue status <id> --set <status>` | ステータス変更のショートカット |
| `tandem issue search <query>` | キーワード検索 |
| `tandem issue runs <id>` | イシュー上のエージェント実行を表示 |
| `tandem issue rerun <id>` | イシューの現在のエージェント担当者向けに新しいタスクを再キューイング |
| `tandem issue comment <id> ...` | ネスト: コメントの表示 / 投稿 |
| `tandem issue subscriber <id> ...` | ネスト: 購読 / 購読解除 |
| `tandem project list/get/create/update/delete/status` | プロジェクトの CRUD |

## エージェントとスキル

| コマンド | 用途 |
|---|---|
| `tandem agent list` | ワークスペースのエージェントを一覧 |
| `tandem agent get <slug>` | エージェントの構成を表示 |
| `tandem agent create ...` | エージェントを作成 |
| `tandem agent update <slug> ...` | エージェントを更新 |
| `tandem agent archive <slug>` | アーカイブ |
| `tandem agent restore <slug>` | アーカイブ済みのエージェントを復元 |
| `tandem agent tasks <slug>` | エージェントのタスク履歴を表示 |
| `tandem agent skills ...` | ネスト: スキルのアタッチ / デタッチ |
| `tandem skill list/get/create/update/delete` | スキルの CRUD |
| `tandem skill import ...` | GitHub、ClawHub、またはローカルマシンからスキルをインポート |
| `tandem skill files ...` | ネスト: スキルのファイルを管理 |

### スキルインポートの競合

`tandem skill import --url <url>` の既定値は `--on-conflict fail` です。同じ名前のスキルがすでに存在する場合、コマンドは構造化された `conflict` 結果で終了し、ワークスペースは変更されません。

既存スキルの作成者で、スキル ID とエージェントの紐付けを維持したまま内容を置き換える場合は `--on-conflict overwrite` を使います。既存スキルを残してコピーを取り込む場合は `--on-conflict rename` を使うと、`-2` のような接尾辞が自動で付きます。同名の項目を単に飛ばす場合は `--on-conflict skip` を使います。

```bash
tandem skill import --url https://skills.sh/acme/repo/review-helper
tandem skill import --url https://skills.sh/acme/repo/review-helper --on-conflict overwrite
tandem skill import --url https://skills.sh/acme/repo/review-helper --on-conflict rename
tandem skill import --url https://skills.sh/acme/repo/review-helper --on-conflict skip
```

## スクワッド

| コマンド | 用途 |
|---|---|
| `tandem squad list` | ワークスペースのスクワッドを一覧 |
| `tandem squad get <id>` | 単一のスクワッドを表示 |
| `tandem squad create --name "..." --leader <agent>` | スクワッドを作成（owner / admin） |
| `tandem squad update <id> ...` | 名前、説明、指示、リーダー、またはアバターを更新 |
| `tandem squad delete <id>` | アーカイブ（ソフト削除） — 割り当て済みのイシューをリーダーに移管 |
| `tandem squad member list/add/remove <squad-id>` | スクワッドメンバーを管理 |
| `tandem squad activity <issue-id> <action\|no_action\|failed> --reason "..."` | スクワッドリーダーエージェントがターンごとに評価を記録するために使用 |

完全なモデルについては[スクワッド](/squads)を参照してください。

## デーモンとランタイム

| コマンド | 用途 |
|---|---|
| `tandem daemon start` | デーモンを起動（デフォルトはバックグラウンド。`--foreground` を追加するとフォアグラウンドで実行） |
| `tandem daemon stop` | デーモンを停止 |
| `tandem daemon restart` | デーモンを再起動 |
| `tandem daemon status` | デーモンがオンラインかどうかと同時実行数を確認 |
| `tandem daemon logs` | デーモンのログを表示 |
| `tandem runtime list` | 現在のワークスペースのランタイムを一覧 |
| `tandem runtime usage` | リソース使用量を表示 |
| `tandem runtime activity` | 最近のアクティビティログ |
| `tandem runtime update <id> ...` | ランタイムの構成を更新 |

## 完全なフラグを確認する

すべてのコマンドが `--help` をサポートしています。

```bash
tandem issue create --help
tandem agent update --help
```

v2 では、各コマンドごとに専用の詳細なリファレンスページを提供する予定です。
