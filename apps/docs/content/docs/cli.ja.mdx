Agora CLI は、Web UI でできるほぼすべての操作をそのまま提供します（[イシュー](/issues)の作成、[エージェント](/agents)の割り当て、[デーモン](/daemon-runtimes)の起動など）。このページでは、すべてのトップレベルコマンドを 1 行の説明とともに一覧します。フラグや例の完全な一覧は `agora <command> --help` を実行してください。

## 認証する

CLI を初めて使うときにこのコマンドを実行して、**パーソナルアクセストークン（PAT）**を取得します。

```bash
agora login
```

ブラウザが自動的に開きます。Web アプリで承認すると、CLI が PAT（`mul_` プレフィックス付き）を `~/.agora/config.json` に保存します。これ以降のすべてのコマンドはこの PAT で認証されます。

<Callout type="tip">
CI やヘッドレス環境では、ブラウザフローをスキップできます。Web アプリの **Settings → Personal Access Tokens** で PAT を作成し、`agora login --token <mul_...>` で直接渡してください。
</Callout>

トークンの種類による違いについては、[認証とトークン](/auth-tokens)を参照してください。

## 認証とセットアップ

| コマンド | 用途 |
|---|---|
| `agora login` | ログインして PAT を保存 |
| `agora auth status` | 現在のログイン状態、ユーザー、ワークスペースを表示 |
| `agora auth logout` | ローカルの PAT を削除 |
| `agora setup cloud` | Agora Cloud のワンショットセットアップ（ログイン + デーモンのインストール） |
| `agora setup self-host` | セルフホストバックエンドのワンショットセットアップ |

## ワークスペースとメンバー

| コマンド | 用途 |
|---|---|
| `agora workspace list` | アクセスできるすべてのワークスペースを一覧 |
| `agora workspace get <slug>` | 1 つのワークスペースの詳細を表示 |
| `agora workspace member list` | 現在のワークスペースのメンバーを一覧 |
| `agora workspace update <id> --name "..." [--description "..."] [--context "..."] [--issue-prefix "..."]` | ワークスペースのメタデータを更新（admin/owner）。長いフィールドは `--description-stdin` / `--context-stdin` を使用できます。 |

## イシューとプロジェクト

<Callout type="info">
`list` 系のコマンド（`agora issue list`、`autopilot list`、`project list` など）は、デフォルトで短く**そのままコピー＆ペーストできる** ID を出力します。イシューは `MUL-123` のようなイシューキー、それ以外のリソースは短い UUID プレフィックスです。以下の後続コマンドの `<id>` 引数は短い ID と完全な UUID のどちらも受け取るため、一般的な流れは `agora issue list` → キーをコピー → `agora issue get MUL-123` となります。正式な UUID が必要なときは `list` コマンドに `--full-id` を渡してください。
</Callout>

| コマンド | 用途 |
|---|---|
| `agora issue list` | イシューを一覧（コピー＆ペーストできるイシューキーを出力） |
| `agora issue get <id>` | 単一のイシューを表示（イシューキーまたは UUID を受け取る） |
| `agora issue create --title "..."` | 新しいイシューを作成 |
| `agora issue update <id> ...` | イシューを更新（ステータス、優先度、担当者など） |
| `agora issue assign <id> --agent <slug>` | エージェントに割り当て（即座にタスクをトリガー） |
| `agora issue status <id> --set <status>` | ステータス変更のショートカット |
| `agora issue search <query>` | キーワード検索 |
| `agora issue runs <id>` | イシュー上のエージェント実行を表示 |
| `agora issue rerun <id>` | イシューの現在のエージェント担当者向けに新しいタスクを再キューイング |
| `agora issue comment <id> ...` | ネスト: コメントの表示 / 投稿 |
| `agora issue subscriber <id> ...` | ネスト: 購読 / 購読解除 |
| `agora project list/get/create/update/delete/status` | プロジェクトの CRUD |

## エージェントとスキル

| コマンド | 用途 |
|---|---|
| `agora agent list` | ワークスペースのエージェントを一覧 |
| `agora agent get <slug>` | エージェントの構成を表示 |
| `agora agent create ...` | エージェントを作成 |
| `agora agent update <slug> ...` | エージェントを更新 |
| `agora agent archive <slug>` | アーカイブ |
| `agora agent restore <slug>` | アーカイブ済みのエージェントを復元 |
| `agora agent tasks <slug>` | エージェントのタスク履歴を表示 |
| `agora agent skills ...` | ネスト: スキルのアタッチ / デタッチ |
| `agora skill list/get/create/update/delete` | スキルの CRUD |
| `agora skill import ...` | GitHub、ClawHub、またはローカルマシンからスキルをインポート |
| `agora skill files ...` | ネスト: スキルのファイルを管理 |

### スキルインポートの競合

`agora skill import --url <url>` の既定値は `--on-conflict fail` です。同じ名前のスキルがすでに存在する場合、コマンドは構造化された `conflict` 結果で終了し、ワークスペースは変更されません。

既存スキルの作成者で、スキル ID とエージェントの紐付けを維持したまま内容を置き換える場合は `--on-conflict overwrite` を使います。既存スキルを残してコピーを取り込む場合は `--on-conflict rename` を使うと、`-2` のような接尾辞が自動で付きます。同名の項目を単に飛ばす場合は `--on-conflict skip` を使います。

```bash
agora skill import --url https://skills.sh/acme/repo/review-helper
agora skill import --url https://skills.sh/acme/repo/review-helper --on-conflict overwrite
agora skill import --url https://skills.sh/acme/repo/review-helper --on-conflict rename
agora skill import --url https://skills.sh/acme/repo/review-helper --on-conflict skip
```

## スクワッド

| コマンド | 用途 |
|---|---|
| `agora squad list` | ワークスペースのスクワッドを一覧 |
| `agora squad get <id>` | 単一のスクワッドを表示 |
| `agora squad create --name "..." --leader <agent>` | スクワッドを作成（owner / admin） |
| `agora squad update <id> ...` | 名前、説明、指示、リーダー、またはアバターを更新 |
| `agora squad delete <id>` | アーカイブ（ソフト削除） — 割り当て済みのイシューをリーダーに移管 |
| `agora squad member list/add/remove <squad-id>` | スクワッドメンバーを管理 |
| `agora squad activity <issue-id> <action\|no_action\|failed> --reason "..."` | スクワッドリーダーエージェントがターンごとに評価を記録するために使用 |

完全なモデルについては[スクワッド](/squads)を参照してください。

## デーモンとランタイム

| コマンド | 用途 |
|---|---|
| `agora daemon start` | デーモンを起動（デフォルトはバックグラウンド。`--foreground` を追加するとフォアグラウンドで実行） |
| `agora daemon stop` | デーモンを停止 |
| `agora daemon restart` | デーモンを再起動 |
| `agora daemon status` | デーモンがオンラインかどうかと同時実行数を確認 |
| `agora daemon logs` | デーモンのログを表示 |
| `agora runtime list` | 現在のワークスペースのランタイムを一覧 |
| `agora runtime usage` | リソース使用量を表示 |
| `agora runtime activity` | 最近のアクティビティログ |
| `agora runtime update <id> ...` | ランタイムの構成を更新 |

## その他

| コマンド | 用途 |
|---|---|
| `agora repo checkout <url>` | エージェントが使用できるようにリポジトリをローカルにクローン |
| `agora config` | ローカルの CLI 構成を表示または編集 |
| `agora version` | CLI のバージョンを出力 |

## 完全なフラグを確認する

すべてのコマンドが `--help` をサポートしています。

```bash
agora issue create --help
agora agent update --help
```

v2 では、各コマンドごとに専用の詳細なリファレンスページを提供する予定です。
