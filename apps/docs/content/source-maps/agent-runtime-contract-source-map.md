## agent-runtime-contract — source map

This page documents the agent runtime contract that the daemon injects into `CLAUDE.md` / `AGENTS.md` / `GEMINI.md` before an agent CLI starts. Every claim is grounded in the symbols below.

| File | Symbols this page depends on |
|---|---|
| `server/internal/daemon/execenv/runtime_config.go` | `InjectRuntimeConfig` (writes the brief to the provider config file), `CleanupRuntimeConfig` (round-trips a user's local repo config), `buildMetaSkillContent` (emits the entire brief consumed here), `runtimeConfigPath` (provider→file mapping: `claude`/`codebuddy`→`CLAUDE.md`, `codex`/`copilot`/`opencode`/`openclaw`/`hermes`/`pi`/`cursor`/`kimi`/`kiro`/`antigravity`→`AGENTS.md`, `gemini`→`GEMINI.md`), `TaskContextForEnv` (trigger discriminators `ChatSessionID`/`QuickCreatePrompt`/`AutopilotRunID`/`TriggerCommentID`; identity fields `AgentName`/`AgentID`/`AgentInstructions`/`RequestingUserProfileDescription`/`RequestingUserName`/`InitiatorName`/`InitiatorEmail`/`InitiatorType`/`WorkspaceContext`; `IssueID`/`TriggerThreadID`/`NewCommentsSince`/`NewCommentCount`/`IsSquadLeader`/`PriorSessionResumed`). Brief headings: `## Output`, `## Mentions`, `## Issue Metadata`, `## Comment Formatting`, `## Showing Code Changes`, `## Instruction Precedence`, `## Important: Always Use the agora CLI`, `## Attachments`. Mention link grammar: `mention://issue/<id>` (inert), `mention://member/<id>` (notifies human), `mention://agent/<id>` (enqueues a run). CLI surface: `agora issue comment add` with `--content`/`--content-stdin`/`--content-file`/`--parent`/`--attachment`; `agora issue comment list` with `--thread`/`--tail`/`--recent`/`--before`/`--before-id`/`--since`; `agora issue metadata list`/`set`/`delete`; `agora issue create`; `agora issue status`; `agora squad activity <id> no_action --reason`; `--output json`/`--full-id`. Recommended metadata keys: `pr_url`,`pr_number`,`pipeline_status`,`deploy_url`,`external_issue_url`,`waiting_on`,`blocked_reason`,`decision`. |
| `server/internal/daemon/execenv/reply_instructions.go` | `BuildCommentReplyInstructions` (platform-split reply form: Windows `--content-file`, Unix quoted-HEREDOC `<<'COMMENT'` + `--content-stdin`; "do NOT reuse --parent from previous turns"), `BuildNewCommentsHint` (warm path, issue-wide count + thread-first read), `BuildResumedCommentsHint` (warm no-delta, `--thread --tail 30`), `BuildColdCommentsHint` (cold path, `--thread <trigger> --tail 30`, `--recent 20`), `activeThreadID`. Stderr cursor labels `Next thread cursor` / `Next reply cursor`. Server cap 2000. Shell-corruption incidents: `MUL-2904`/`OKK-497` (backtick/`$()`/`$VAR`), `#2198`/`#2236`/`#2376` (Windows ASCII codepage drop), `MUL-1467` (Codex literal `\n`). |
| `server/internal/daemon/prompt.go` | `BuildPrompt` (per-turn dispatch by trigger), `buildCommentPrompt` (embeds trigger comment, re-emits reply instructions per turn so resumed `--parent` can't drift), `buildQuickCreatePrompt` (single `agora issue create`, no get/comment, `Created <identifier-or-id>: <title>`), `buildChatPrompt`, `buildAutopilotPrompt` (run-only, no issue id). Flat-timeline 2000 cap + `--recent`/`--before`/`--before-id` paging + `--since` polling note. |

**Drift rule (builtin_skills source-traced contract, per `CLAUDE.md`):** when any symbol, brief heading, mention grammar entry, CLI flag, or recommended metadata key listed above moves, is renamed, or changes behavior, update both `content/docs/developers/agentic/agent-runtime-contract.mdx` and this sidecar in the **same PR**. CI/builtin-skill drift checks treat a stale page as teaching behavior the daemon no longer emits.
